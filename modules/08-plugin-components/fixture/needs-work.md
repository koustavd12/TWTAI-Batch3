# Getting started with the Orders API

## Overview

To start using the Orders API, you need an API token. Open the Settings page of
the developer console and click **Create Token**.

Paste the token into your client.
Authorize the token for the API.

## Authentication

All requests must be authenticated. Send the token in the Authorization header.

Read the reference documentation. It covers every endpoint, including
